# Glossario essenziale Bash

| Termine | Definizione |
|---|---|
| Shell | Programma che interpreta comandi e offre un ambiente di esecuzione. |
| Bash | Bourne Again SHell, shell e linguaggio di scripting. |
| Terminale | Applicazione che consente di interagire testualmente con una shell. |
| Script | File di testo con una sequenza di istruzioni. |
| Shebang | Prima riga che indica l'interprete da utilizzare, ad esempio `#!/usr/bin/env bash`. |
| Variabile | Nome associato a un valore. |
| Espansione | Sostituzione di una variabile o espressione con il suo valore. |
| Quoting | Uso di apici o escape per controllare come la shell interpreta il testo. |
| stdin | Flusso standard di ingresso, descrittore 0. |
| stdout | Flusso standard di uscita, descrittore 1. |
| stderr | Flusso standard degli errori, descrittore 2. |
| Redirezione | Deviazione di un flusso verso file o altra destinazione. |
| Pipeline | Collegamento tra comandi con `|`. |
| Exit status | Codice numerico che indica l'esito di un comando o script. |
| PID / PPID | Identificatore di un processo / identificatore del processo padre. |
| Glob | Modello di ricerca file interpretato dalla shell, ad esempio `*.txt`. |
| Cron | Servizio tradizionale per pianificare attività periodiche. |
| Dry-run | Modalità di anteprima che mostra le operazioni senza applicarle. |
