# Modulo 4 – Bash Scripting

Repository didattico del modulo Bash Scripting.

- `dispense/`: schede teoriche in Markdown.
- `codice/`: script Bash, esempi e laboratori.

Gli script vanno provati in directory di laboratorio con dati non importanti.

## Esecuzione

```bash
chmod +x codice/percorso/script.sh
bash codice/percorso/script.sh
```

Consultare le dispense in ordine numerico.


## Percorso didattico e dispense

Le dispense si trovano in `dispense/` e sono numerate secondo la progressione didattica.
Ogni scheda tematica (01–12) è progettata per una lezione di circa 60 minuti e contiene:
obiettivi, spiegazione, esempi, scansione temporale, laboratorio, collegamenti ai file
di codice e domande di verifica.

Consultare `dispense/INDICE-DISPENSE-E-CODICE.md` per la corrispondenza tra lezioni
e script. Le esercitazioni e il progetto finale sono raccolti nelle schede 13 e 14.
