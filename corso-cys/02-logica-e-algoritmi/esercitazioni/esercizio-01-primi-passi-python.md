# Esercitazione 01 – Primi passi con Python

Obiettivo: configurare l'ambiente e realizzare i primi script.

Attività:
1. Verificare l'installazione di Python 3.12.
2. Configurare l'IDE e creare una cartella di lavoro.
3. Scrivere ed eseguire uno script `.py`.
4. Utilizzare `print()` e `input()`.
5. Inserire commenti e correggere semplici errori di sintassi.

Produrre uno script che acquisisca alcuni dati e visualizzi un riepilogo.
