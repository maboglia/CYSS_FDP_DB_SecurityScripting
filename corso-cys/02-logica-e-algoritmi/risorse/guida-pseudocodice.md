# Guida allo pseudocodice

Convenzioni introduttive:

```text
INIZIO
    LEGGI valore
    SE valore > soglia ALLORA
        SCRIVI "Soglia superata"
    ALTRIMENTI
        SCRIVI "Valore nella norma"
    FINE SE
FINE
```

Parole chiave suggerite:
- `INIZIO` / `FINE`
- `LEGGI` / `SCRIVI`
- `ASSEGNA`
- `SE` / `ALTRIMENTI` / `FINE SE`
- `MENTRE` / `FINE MENTRE`
- `PER` / `FINE PER`

Lo pseudocodice è indipendente dal linguaggio di programmazione: deve rendere
chiara la logica della soluzione senza imporre una sintassi eseguibile.
