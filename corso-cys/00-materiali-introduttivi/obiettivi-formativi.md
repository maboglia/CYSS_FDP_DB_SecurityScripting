# Obiettivi formativi

## 1. Obiettivo generale

Sviluppare competenze di base nella programmazione, nella gestione
dei database e nello scripting, applicandole a situazioni operative
riconducibili all'amministrazione dei sistemi e alla cybersecurity.

Lo studente dovrà acquisire la capacità di analizzare problemi,
progettare soluzioni algoritmiche, implementare programmi,
interrogare basi di dati e automatizzare attività tecniche.

## 2. Competenze attese

Al termine del percorso lo studente sarà in grado di:

1. Comprendere i principali componenti di un sistema informatico.
2. Interpretare semplici problemi e tradurli in algoritmi.
3. Scrivere programmi utilizzando il linguaggio Python.
4. Organizzare il codice attraverso funzioni e moduli.
5. Utilizzare strutture dati fondamentali.
6. Gestire file, directory e processi attraverso Bash.
7. Progettare semplici strutture di database.
8. Scrivere query SQL per estrarre e modificare informazioni.
9. Interagire con database PostgreSQL.
10. Comprendere i principi dei database NoSQL.
11. Realizzare API REST utilizzando FastAPI.
12. Validare dati attraverso Pydantic.
13. Gestire la persistenza attraverso SQLAlchemy.
14. Analizzare dati e file di log.
15. Riconoscere vulnerabilità comuni nei sistemi software.
16. Applicare principi fondamentali di sviluppo sicuro.

## 3. Conoscenze

Lo studente acquisirà conoscenze relative a:

### Informatica e algoritmi

- Architettura di un sistema informatico.
- Sistemi operativi.
- Rappresentazione dei dati.
- Algoritmi e strutture di controllo.
- Pseudocodice e diagrammi di flusso.

### Programmazione

- Sintassi del linguaggio Python.
- Tipi di dato e operatori.
- Condizioni e iterazioni.
- Liste, tuple, dizionari e insiemi.
- Funzioni e moduli.
- Programmazione orientata agli oggetti.
- Gestione delle eccezioni.

### Sistemi e scripting

- Shell Linux.
- Comandi fondamentali.
- Variabili e strutture di controllo Bash.
- Gestione di file e directory.
- Automazione di operazioni.

### Database

- Modello relazionale.
- Entità e relazioni.
- Chiavi e vincoli.
- Normalizzazione.
- Linguaggio SQL.
- Database PostgreSQL.
- Introduzione ai database NoSQL.

### Backend

- Architettura client-server.
- Protocollo HTTP.
- API REST.
- FastAPI.
- Validazione dei dati.
- ORM e persistenza.

### Cybersecurity

- Principi di sicurezza delle informazioni.
- Analisi dei log.
- Controllo degli accessi.
- Sicurezza dei database.
- SQL Injection.
- Vulnerabilità applicative.
- OWASP Top 10.

## 4. Abilità operative

Lo studente dovrà essere in grado di:

- Configurare un ambiente di sviluppo.
- Utilizzare il terminale Linux.
- Scrivere ed eseguire programmi Python.
- Realizzare script per automatizzare attività.
- Leggere e manipolare file di testo e CSV.
- Elaborare informazioni mediante strutture dati.
- Scrivere query SQL.
- Creare tabelle e relazioni.
- Realizzare semplici applicazioni backend.
- Consumare e testare API REST.
- Analizzare informazioni contenute nei log.
- Individuare situazioni potenzialmente anomale.
- Applicare controlli e validazioni agli input.
- Documentare il codice sviluppato.

## 5. Competenze applicate alla cybersecurity

Particolare attenzione sarà dedicata all'applicazione
delle competenze informatiche in scenari di sicurezza.

Esempi di attività:

- Analizzare accessi e tentativi di autenticazione.
- Individuare anomalie nei file di log.
- Contare e classificare eventi sospetti.
- Automatizzare controlli su file e directory.
- Verificare la corretta gestione dei privilegi.
- Proteggere le interrogazioni SQL.
- Riconoscere tentativi di SQL Injection.
- Implementare validazioni nei servizi backend.
- Gestire correttamente errori e informazioni sensibili.

Le esercitazioni di sicurezza saranno svolte esclusivamente
in ambienti controllati e autorizzati.

## 6. Competenze trasversali

Durante il percorso saranno sviluppate anche:

- Capacità di problem solving.
- Pensiero logico e computazionale.
- Autonomia operativa.
- Precisione e attenzione ai dettagli.
- Capacità di documentazione.
- Collaborazione e lavoro di gruppo.
- Capacità di analisi e verifica dei risultati.
- Consapevolezza delle responsabilità professionali.

## 7. Risultati di apprendimento osservabili

Al termine delle attività lo studente dovrà saper realizzare
autonomamente semplici prodotti tecnici, tra cui:

| Prodotto | Risultato atteso |
|---|---|
| Algoritmo | Risoluzione di un problema attraverso pseudocodice o diagramma |
| Programma Python | Elaborazione di dati e applicazione di condizioni |
| Script Bash | Automazione di operazioni su file e directory |
| Database | Progettazione e interrogazione di una base dati |
| API REST | Realizzazione di servizi backend con validazione |
| Analisi log | Elaborazione e identificazione di eventi anomali |
| Project work | Integrazione delle competenze in un caso applicativo |

## 8. Criteri generali di valutazione

La valutazione terrà conto di:

- Correttezza delle soluzioni.
- Comprensione dei concetti.
- Capacità di progettazione.
- Qualità e leggibilità del codice.
- Utilizzo appropriato degli strumenti.
- Capacità di individuare e correggere errori.
- Applicazione dei principi di sicurezza.
- Autonomia nello svolgimento delle attività.
- Capacità di documentare il lavoro.
