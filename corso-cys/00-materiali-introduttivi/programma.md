# Fondamenti di Programmazione, Basi di Dati e Scripting per la Sicurezza

## 1. Presentazione del percorso

Il percorso formativo introduce gli studenti ai principali strumenti
e alle tecniche di programmazione, gestione dei dati e automazione
utilizzati nell'ambito della cybersecurity.

L'obiettivo è sviluppare competenze tecniche che consentano di
comprendere il funzionamento dei sistemi informatici, analizzare
informazioni, automatizzare attività e realizzare semplici applicazioni
backend a supporto della sicurezza.

Il percorso adotta un approccio prevalentemente laboratoriale,
integrando le conoscenze teoriche con esercitazioni pratiche.

## 2. Finalità didattiche

Al termine del percorso lo studente dovrà essere in grado di:

- Comprendere i principali concetti dell'informatica.
- Progettare semplici algoritmi.
- Sviluppare programmi utilizzando Python.
- Automatizzare operazioni attraverso Bash scripting.
- Progettare e interrogare database relazionali.
- Comprendere i fondamenti dei database NoSQL.
- Realizzare semplici API REST con FastAPI.
- Interagire con database attraverso SQLAlchemy.
- Analizzare dati e log in contesti di sicurezza.
- Riconoscere alcune vulnerabilità comuni.
- Applicare principi di sicurezza nella scrittura del codice.

## 4. Metodologia didattica

Il percorso utilizza una metodologia basata su:

- Lezioni teoriche introduttive.
- Dimostrazioni pratiche.
- Esercitazioni guidate.
- Attività individuali.
- Attività collaborative.
- Analisi di casi concreti.
- Laboratori applicativi.
- Project work.

Ogni argomento sarà accompagnato, ove possibile, da esempi
di codice e scenari riconducibili alla cybersecurity.

## 5. Organizzazione delle attività

Le attività saranno organizzate attraverso il repository GitHub.

Ogni modulo contiene materiali didattici, esempi, esercitazioni
e risorse di approfondimento.

Gli studenti potranno utilizzare il repository per:

- Consultare le lezioni.
- Scaricare gli esempi.
- Svolgere le esercitazioni.
- Archiviare il proprio codice.
- Documentare le soluzioni sviluppate.

## 6. Verifica degli apprendimenti

La valutazione potrà comprendere:

- Verifiche teoriche.
- Esercizi di programmazione.
- Interrogazioni di database.
- Realizzazione di script.
- Sviluppo di API.
- Analisi di scenari di sicurezza.
- Project work individuali o di gruppo.

## 7. Regole di laboratorio

Tutte le attività di cybersecurity devono essere svolte
esclusivamente in ambienti autorizzati e predisposti a scopo didattico.

Non è consentito effettuare scansioni, test di vulnerabilità,
accessi o altre attività sui sistemi di terzi senza esplicita
autorizzazione.

## 8. Repository didattico

Il repository costituisce il riferimento principale per
l'organizzazione dei materiali e delle attività formative.

La struttura è suddivisa per argomenti e moduli, in modo
da facilitare la consultazione e il progressivo apprendimento.
